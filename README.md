# Brainfuck Interpreter

This command-line tool is a small interpreter for the Brainfuck esoteric programming language, which uses wrapping around the data array and cells.

To learn more about the aforementioned esoteric language, you can read the [Wikipedia article](https://en.wikipedia.org/wiki/Brainfuck) and visit this [source](https://www.brainfuck.org), which contains very interesting code samples and additional information.
